# Testes do SUN V2

Este diretório pertence exclusivamente ao SUN V2.

Os testes serão organizados depois da aprovação do contrato do Temporal Core. A primeira etapa produzirá modelos de referência e testes de propriedades independentes da implementação de produção.

Nenhum teste legado será copiado sem revisão de finalidade, premissas, cobertura e validade para a arquitetura V2.
